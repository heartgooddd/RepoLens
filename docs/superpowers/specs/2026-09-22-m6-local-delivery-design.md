# M6 本地交付设计

日期：2026-09-22。用户已确认“源码安装＋双击脚本”方案，并授权实施、技术验收后 G2/G3；真实试用单独记账。

## 范围

面向当前 macOS，交付首次安装、启动、停止、配置密钥、停服备份和恢复。沿用 Python 3.14、Node 22、两个虚拟环境、固定依赖锁和 macOS 沙箱。不制作签名 App，不引入 Docker，不公开监听，不自动调用模型。

## 安装与启动

根目录提供可双击的 Install.command、Start.command、Stop.command。脚本解析自身目录，支持空格路径；检查 Git、Python、Node/npm 后安装依赖，构建前端。PocketFlow 从固定官方 HTTPS 来源获取 Commit 05b24cbbb0fe409c5e23c9791f0342f07524ffdc；保留 LICENSE，核验来源、HEAD、工作区，不覆盖已有不匹配或修改过的目录。下载失败有清楚错误，不能借用开发机器的 upstream 伪装安装成功。

本地交付使用构建后的静态前端及后端 API，同一 127.0.0.1:8000 服务提供页面，减少两个端口/进程的启动故障面；开发 Vite 工作流保持不变。启动器检查锁文件对应安装状态、前端构建、上游和隔离能力，缺密钥仅禁用真实任务。仅在明确启用后提供真实配方，仍需用户从页面启动。管理进程有所有权标记、健康检查、日志和退出清理；停止只发送给本工具拥有的进程，拒绝按端口盲杀。

## 停服维护与数据边界

后端全生命周期持有数据目录排他锁；备份使用同一锁，服务运行时拒绝，涵盖同步上传和异步任务。SQLite backup API 生成一致性数据库，复制登记 snapshots/runs，排除测试、锁、临时缓存和密钥。备份含格式版本、代码 Commit、迁移版本、文件大小和 SHA-256 清单，并检查数据库引用文件、外键及完整性。

恢复只允许全新目标目录，验证清单路径、链接、内容哈希和数据库引用后原子发布；失败不替换当前 var，也不覆盖现有目录。不执行备份内容。密钥不随备份，恢复后按文档重新配置。备份可能包含私有源码/模型结果，应视为敏感数据。支持通过 REPOLENS_DATA_DIR 选择恢复目录。

## 验收

从仅 Git 跟踪内容的全新路径安装；不存在 upstream、venv、node_modules 或密钥。验证固定来源实际下载、重复安装、可理解的缺依赖/端口占用/版本不匹配报错、双击入口、健康检查、仅本机监听、重复启动和停止。

自动测试覆盖服务与备份互斥、SQLite 和引用文件一致性、篡改/链接/路径越界/已存在目标拒绝。实际备份现有数据，恢复到独立目录，通过页面打开真实项目、源码依据及 M3 历史结果；新页面运行用明确标识的替身或离线模型夹具，不发送付费请求。
